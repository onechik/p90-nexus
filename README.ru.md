# P90 Nexus 0.3.0 и P90 Rooms 0.2.0

## Установить или обновить Nexus

1. Закрой игру.
2. Открой папку **p90 Nexus** и дважды нажми **Setup.cmd**.
3. В появившемся окне выбери папку, в которой лежит **SCP Project 90.exe**.
4. Дождись сообщения «Готово». Установщик сам выберет новую установку или обновление. При обновлении настройки и плагины сохраняются; заменяемые файлы копируются в резервную папку.

## Установить плагин комнат

1. Из папки **plugins** скопируй целиком папку **P90.Rooms**.
2. Вставь её в **P90 → plugins** внутри установленной игры.
3. Запусти игру заново. Обновлять файлы игры через Steam для этого не нужно.
4. Открой **P90 Console.cmd** в папке игры и введи **pl**. В списке должен быть **p90.rooms**. Список команд и их описания: **com**.

Получится: `<папка игры>\P90\plugins\P90.Rooms\P90.Rooms.dll`. Если внутри появилась ещё одна папка P90.Rooms, убери лишний уровень вложенности.

Дальше плагины устанавливаются таким же способом: папка плагина → P90\plugins → полный перезапуск игры. Для обновления замени содержимое папки новой версией при закрытой игре. Для удаления перенеси папку за пределы P90\plugins; настройки в P90\config останутся. Команда **res** перезапускает уже загруженный плагин; для добавления/замены DLL нужен перезапуск самой игры.

Работа на компьютерах других игроков подтверждена Федором. На их компьютеры Nexus и серверные плагины устанавливать не требуется. Подробное руководство по комнатам: **plugins\P90.Rooms\ROOMS.ru.md**. Документация ядра: **p90 Nexus\Documentation**.
