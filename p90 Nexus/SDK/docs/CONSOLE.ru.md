# Простое окно управления

## Как открыть

1. Открой папку игры — там, где находится `SCP Project 90.exe`.
2. Найди **P90 Console.cmd** и дважды щёлкни по нему.
3. Откроется окно с подсказками. После `P90:` напиши `plugins` и нажми Enter.

Ничего устанавливать отдельно не нужно. Файл можно запускать до игры: если она ещё закрыта, консоль сообщит об этом и останется открытой. После запуска игры дождись меню и снова введи команду. Консоль сначала ищет работающую игру рядом с собой, затем автоматически находит единственную другую запущенную копию с P90, в том числе Steam-копию. Строка «Подключение к игре» показывает выбранную папку. Проверяются PID, путь EXE и время запуска. При нескольких подходящих копиях без локальной консоль попросит выбрать нужную; можно открыть её рядом с нужной игрой или запустить scripts/P90-Console.ps1 с параметром -GamePath и путём к игре.

## Короткие команды

| Полная | Короткая |
| --- | --- |
| plugins | pl |
| commands | com |
| help | h |
| exit | ex |
| restart | res |
| start | st |
| stop | sp |
| status | stat |
| players | ppl |
| announce | ann |
| clear | cl |

Примеры: `res sample.server`, `sp sample.server`, `ann Привет всем!`. Команда `cls` по-прежнему очищает окно; `cl` убирает объявление в игре.

## Что писать

При открытии окна консоль получает из игры список команд всех работающих плагинов. `help` и `commands` запрашивают его заново; после start, stop и restart он обновляется автоматически. Новая команда плагина не требует изменения консоли: напиши её имя и аргументы прямо после P90:. Остановленный плагин убирает свои команды из актуального списка.

Консоль видит команды, зарегистрированные через P90 API. Произвольные функции внутри DLL, которые автор не зарегистрировал как команды, в списке не появятся. `help`/`com` группируют команды по ID плагина и показывают описание и строку «Как использовать». Тексты задаёт автор при регистрации команды; для старого плагина без описаний виден владелец и сообщение, что автор их не добавил. Если игру запустили уже после открытия консоли, введи help.

Для владельцев и описаний требуется обновлённое ядро: при старом консоль покажет предупреждение и простой список. Из полного комплекта обновление выполняется при закрытой игре: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update.ps1 -GamePath "D:\Games\SCP Project 90"`. Это сохраняет резервную копию заменяемых файлов. На текущем компьютере обновление может быть уже применено — смотри итог работы в чате.

| Напиши и нажми Enter | Что произойдёт |
| --- | --- |
| `plugins` | Появится список плагинов и их состояние |
| `stop sample.server` | Тестовый плагин остановится |
| `start sample.server` | Он снова включится |
| `restart sample.server` | Он перезапустится и перечитает настройки |
| `commands` | Появится список команд установленных плагинов |
| `status` | Покажет состояние сервера |
| `players` | Покажет игроков |
| `announce Привет всем!` | Отправит объявление в игру |
| `clear` | Уберёт объявление в игре |
| `cls` | Очистит текст в этом окне |
| `help` | Снова покажет подсказки |
| `exit` | Закроет консоль, оставив игру работающей |

`sample.server` — ID тестового плагина. Чтобы управлять другим, возьми его ID из списка `plugins` и подставь вместо sample.server. Если остановишь sample.server, команды status, players, announce и clear исчезнут до его следующего запуска — это его функции.

Объявления работают на твоём сервере после появления персонажа. В главном меню отправлять их ещё некуда. Текст после announce можно писать без кавычек. Для остальных команд аргумент с пробелами заключай в кавычки: `myplugin.command "текст с пробелами"`.

Команды новых плагинов вводятся прямо в это окно, например `onechik.hello.hello`. Полные имена `p90.plugins` и `server.status` тоже работают. Это окно управления P90: обычные команды Windows и PowerShell здесь не исполняются.

После команды не нужно заново открывать окно — просто вводи следующую. Можно закрыть окно крестиком: это не останавливает плагины и не закрывает игру. Замена DLL по-прежнему требует полного перезапуска игры; restart только останавливает и запускает уже загруженный плагин.

## Если игра не отвечает

Проверь, что запущена нужная копия игры и она уже загрузилась. При таймауте команда ещё может выполниться: перед повтором объявления или другой операции посмотри на результат в игре. Само окно продолжает работать после ошибки.

## Передача другим людям

В обновлённом полном комплекте эти файлы устанавливаются автоматически. Для уже установленного Nexus перенеси три файла с сохранением расположения (P90.ps1 нужно обновить вместе с консолью):

```text
<папка игры>/P90 Console.cmd
<папка игры>/scripts/P90-Console.ps1
<папка игры>/scripts/P90.ps1
```

Обновлённый scripts/P90.ps1 нужен для выбора другой запущенной копии игры. Перезапуск игры для добавления окна не требуется. Подробные команды и диагностика — в [руководстве оператора](OPERATIONS.ru.md).
