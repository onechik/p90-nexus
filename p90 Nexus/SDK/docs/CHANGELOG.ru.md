# P90 Nexus — история выпуска

## 0.3.0 — 1 октября 2026

Плагины устанавливаются отдельными папками в P90/plugins с полным перезапуском игры. Поддерживаются дополнительные управляемые DLL рядом с плагином и прежние одиночные DLL. Папка получает приоритет перед старой копией той же сборки. В release добавлены Setup.cmd/Setup.ps1 с выбором папки и автоматическим режимом установки/обновления, документация и отдельный пакет P90 Rooms 0.2.0. API major 1 сохранён. Федор подтвердил работу P90 Rooms на других компьютерах.

## Дополнение от 1 октября 2026 — владельцы и описания команд

Добавлены CommandInfo, расширенная регистрация с description/usage, каталог p90.commandinfo и группировка справки по настоящему ID владельца. Старый метод регистрации и текстовый p90.commands сохранены. Обновлены sample.server и шаблон SDK; старые плагины не обязаны добавлять тексты. Для использования новой регистрации нужны обновлённые SDK и ядро. В комплект добавлен Update.ps1 с резервным копированием и откатом при ошибке копирования. Описание команды не является схемой валидации её аргументов.

## Дополнение от 1 октября 2026 — простая консоль

Добавлены алиасы pl/com/h/ex/res/st/sp/stat/ppl/ann/cl и автоматическое подключение к другой запущенной копии с P90. Причина ложного сообщения об отсутствии игры: консоль в рабочей копии читала её старую сессию, пока пользователь играл в Steam-копии. Подключение и команды списка проверены на реальной Steam-копии; проверки PID, пути и времени запуска сохранены. P90.ps1 получил необязательный -GamePath; без него прежнее поведение не меняется.

Уточнение: help теперь получает список команд из работающих плагинов при открытии окна и по запросу; start/stop/restart обновляют его автоматически. Новые зарегистрированные команды работают без изменения консоли. Проверено 17 сценариев в PS5.1 и PS7 с имитацией смены состава команд.

- Окно управления запускается двойным щелчком по P90 Console.cmd.
- Короткие команды plugins, start, stop, restart, status, players, announce, clear и встроенная help.
- Таблица плагинов со статусами по-русски, понятная ошибка при закрытой игре, продолжение работы после отказа команды.
- Пользовательский ввод не исполняется как PowerShell; команды передаются через существующий P90.ps1.
- DLL ядра и API не менялись. Для существующих установок достаточно добавить файл запуска и scripts/P90-Console.ps1.
- Проверка консоли использует имитацию ответов игры; она не является новой проверкой игровых или сетевых функций.

## 0.2.0 — первый документированный выпуск, 27 сентября 2026

- Самостоятельный комплект установки на чистую поддерживаемую SCP Project 90.
- Собственное ядро поверх подтверждённого пути UnityDoorstop → BepInEx IL2CPP.
- Публичный API major 1, события наблюдения сервера/игроков, штатные объявления.
- Локальное управление плагинами через PowerShell 5.1/7; исправлено сравнение UTC времени процесса.
- Учёт и очистка регистраций, отказ при неподдерживаемой сборке, модельные и игровые проверки.
- Один тестовый sample.server; SDK с генератором и самостоятельным примером.
- Руководства оператора, автора плагинов, разработчика ядра; исходники нашего фреймворка и манифест выпуска.
- Подтверждение Федора о работе сборки у него и у других людей.

Финальное оформление не меняет проверенные исполняемые DLL: номер 0.2.0 сохранён. Это первый выпуск с ограниченным игровым API, а не обещание поддержки всех механик. В частности, роли, предметы, урон, dedicated, горячая выгрузка DLL, удалённая консоль и подробная матрица всех сетевых сценариев в заявленную поддержку не входят.
