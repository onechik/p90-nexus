# P90 Nexus 0.3.0

Серверный фреймворк плагинов для SCP Project 90. Для игры с серверными плагинами Nexus устанавливается у хоста. Публичный API: major 1, net6.0; поддерживается сборка игры из supported-game.json.

## Установка и обновление

1. Закрой SCP Project 90.
2. Дважды нажми **Setup.cmd**.
3. Выбери папку с **SCP Project 90.exe** и дождись сообщения «Готово».

При чистой игре выполняется установка загрузчика, runtime и ядра. При уже установленном Nexus обновляются системные DLL и консоль; плагины, конфиги и комнаты сохраняются. Прежние системные файлы копируются в P90/backups. Для установки не нужны .NET SDK или знания программирования.

Папку выбирай именно ту, из которой запускаешь игру. Рабочая копия и Steam-копия имеют отдельные установки. Перед первым запуском открой Steam. Первая загрузка после чистой установки создаёт игровые interop-сборки и занимает больше времени.

## Плагины

Скопируй папку плагина в **P90\plugins** внутри игры, затем полностью перезапусти игру. Пример: `P90\plugins\P90.Rooms\P90.Rooms.dll`. Вложенная дополнительная папка с тем же именем не нужна. DLL и дополнительные управляемые библиотеки автора лежат рядом; Sources и Examples не загружаются.

Одиночные DLL старых установок также поддерживаются. Если одна сборка есть и в новой папке, и отдельно, используется новая папка. При удалении плагина убери обе копии, если сохранилась старая. Разные версии зависимостей в одном процессе не изолируются.

В этом комплекте отдельно, в соседней **plugins\P90.Rooms**, находится плагин собственных комнат. В базовом ядре есть диагностический sample.server, предоставляющий команды players/status/announce. Он устанавливается на чистую игру, а при обновлении сохраняется, если уже присутствует.

## Консоль

В папке установленной игры дважды нажми **P90 Console.cmd**.

| Ввод | Действие |
|---|---|
| `pl` | Плагины и состояние |
| `com` | Команды, ID владельцев, описание и использование |
| `players` | Игроки и ConnectionId |
| `h` | Справка |
| `sp ID` / `st ID` | Остановить / запустить плагин |
| `res ID` | Перезапустить уже загруженный плагин |
| `ex` | Закрыть консоль |

Для добавления и обновления файлов плагина нужен перезапуск самой игры. Проверка целостности/обновление игры через Steam не является установкой плагина.

**GameFiles** содержит устанавливаемые файлы. **SDK** и **Development** предназначены для авторов и не копируются в игру автоматически. В комплект не входят оригинальные файлы игры, пользовательские комнаты, логи и данные консоли.

Если в Setup есть ошибка, прочитай сообщение в его окне. При неподдерживаемой игре установщик откажется от изменений. Для диагностики после запуска используются BepInEx/LogOutput.log и P90/logs.

Для запуска из PowerShell без окна выбора: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -GamePath "D:\Games\SCP Project 90"`.
