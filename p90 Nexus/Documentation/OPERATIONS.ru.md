# Управление P90 Nexus

**Самый простой способ:** открой двойным щелчком `P90 Console.cmd` рядом с EXE игры. В появившемся окне введи `plugins`, `stop sample.server` или `help`. Полная [инструкция по простому окну](CONSOLE.ru.md). Приведённые ниже PowerShell-команды сохранены для автоматизации и диагностики.

## Установка и повседневная работа

Установку на чистую игру описывает README в корне комплекта. Для уже работающей установки не запускай Install.ps1 повторно. Обычный порядок: Steam → EXE нужной копии → главное меню → свой сервер → PowerShell из папки этой игры. На стороне подключающегося игрока Nexus для заявленных серверных функций не требуется.

Тестовый плагин поставки — `sample.server`. В рабочей копии разработчика могут присутствовать ещё два технических плагина; это не означает, что они обязательны для пользователей.

```powershell
Set-Location -LiteralPath 'D:\Games\SCP Project 90'
.\scripts\P90.ps1 p90.plugins | Format-List
.\scripts\P90.ps1 server.status | Format-List
```

Если политика исполнения запрещает запуск, можно использовать `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\P90.ps1" p90.plugins`. Скрипт должен лежать внутри scripts той же запущенной копии: путь вычисляется относительно самого файла, а не текущего каталога.

## Все команды поставки

| Команда | Аргументы | Результат |
| --- | --- | --- |
| `p90.help` | нет | Краткая справка, включая команды sample.server |
| `p90.plugins` | нет | JSON со списком ID, Version, State |
| `p90.commands` | нет | Зарегистрированные команды плагинов; встроенные p90.* в этот список не входят |
| `p90.commandinfo` | нет | JSON-каталог команд с PluginId, Description и Usage; простая консоль показывает его через com/help |
| `p90.stop` | один ID | Stop и снятие регистраций |
| `p90.start` | один ID | Start уже обнаруженного неактивного плагина |
| `p90.restart` | один ID | Stop, затем Start, если Stop успешен |
| `server.status` | нет | ServerSnapshot в JSON |
| `server.players` | нет | Массив наблюдаемых готовых персонажей |
| `server.announce` | текст либо нет | Отправка текста; без аргументов — DefaultAnnouncement |
| `server.clear` | нет | Отправка пустого объявления |

`server.*` существует только пока sample.server активен. p90.help содержит статическую подсказку и может упоминать их даже после остановки образца. Команды p90.* нужно писать точно в нижнем регистре.

```powershell
.\scripts\P90.ps1 -Command server.announce -Arguments 'Добро пожаловать!' | Format-List
.\scripts\P90.ps1 -Command p90.stop -Arguments sample.server | Format-List
.\scripts\P90.ps1 -Command p90.start -Arguments sample.server | Format-List
```

Для нескольких аргументов в текущей PowerShell-сессии используй массив: `-Arguments @('первый', 'второй')`. Текст с пробелами заключай в кавычки. Ответ — объект `Success`, `Message`; Format-List помогает увидеть длинный JSON без обрезания таблицей.

**Автоматизация:** отрицательный ответ команды не обязательно даёт ненулевой exit code скрипта. Проверяй Success:

```powershell
$reply = & '.\scripts\P90.ps1' server.status
if (-not $reply.Success) { throw $reply.Message }
$state = $reply.Message | ConvertFrom-Json
$state | Format-List
```

`-TimeoutSeconds` от 1 до 30, по умолчанию 20. Таймаут ожидания не отменяет уже переданную команду: она может исполниться позже, пока её срок 30 секунд не истёк. Перед повтором операции с последствиями проверь журнал и состояние игры.

## Добавить, остановить, обновить, удалить

Добавление: закрыть игру → скопировать папку плагина в P90/plugins → запустить → проверить Active. Внутри этой папки DLL плагина и дополнительные управляемые библиотеки должны лежать непосредственно рядом, например P90/plugins/P90.Rooms/P90.Rooms.dll. Вложенные Sources, Examples и другие уровни не сканируются. Отдельные DLL прямо в P90/plugins также поддерживаются. При наличии старой одиночной DLL и новой папки с той же сборкой используется папка; старую DLL можно убрать при закрытой игре. Разные версии общей зависимости не изолируются.

Автоматического обнаружения новой DLL по команде start нет: Start работает с уже загруженным объектом. Добавление и замена файлов требуют полного перезапуска игры.

Остановка через p90.stop обратима. Повторная остановка неактивного плагина допустима. Start активного плагина отклоняется. Faulted означает ошибку старта; исправь причину в конфиге и повтори Start, а при изменении DLL перезапусти игру. Ошибка конструктора или метаданных может не создать запись в списке; ищи причину в core.jsonl.

Обновление и удаление плагинов выполняются только при закрытой игре. p90.restart создаёт новый контекст для того же экземпляра из уже загруженной DLL. Для отключения между запусками перенеси папку плагина за пределы P90/plugins; если есть прежняя одиночная DLL, перенеси и её. Список включённых/отключённых плагинов в отдельном конфиге не хранится: при следующем запуске обнаруженные DLL снова запускаются.

При Stop ядро убирает свои команды и подписки. Оно не умеет принудительно останавливать произвольные потоки и внешние ресурсы плохо написанного плагина. Для полного освобождения процесса закрой игру.

## Каталоги и резервные копии

| Путь относительно игры | Содержимое |
| --- | --- |
| `BepInEx/plugins/P90.Loader` | Четыре системные DLL |
| `BepInEx/interop` | Сгенерированные привязки к игре |
| `BepInEx/config/BepInEx.cfg` | Настройки загрузчика |
| `P90/plugins` | Пользовательские плагины |
| `P90/config/<id>.json` | Настройки плагина |
| `P90/logs/<id>.jsonl` | Журнал плагина, дописывается между запусками |
| `P90/logs/core.jsonl` | Жизненный цикл, результаты локальных команд |
| `P90/logs/runs/<UTC-PID>/core.jsonl` | Журнал конкретного запуска загрузчика/адаптера |
| `P90/control` | Временный файловый обмен со скриптом |
| `BepInEx/LogOutput.log` | Журнал загрузчика и перенаправленные игровые сообщения |

При закрытой игре сохраняй DLL плагинов, их конфиги и версию комплекта. Control не нужен для переноса. Данные самой игры и Steam живут по правилам игры; это руководство не меняет их. Для полного отката хранить чистую копию игры удобнее, чем вручную смешивать версии загрузчиков.

Конфиг sample.server: `P90/config/sample.server.json`, свойство DefaultAnnouncement. После изменения корректного UTF-8 JSON вызови p90.restart sample.server либо перезапусти игру. Неверный JSON не затирается стандартными настройками. Журналы не ротируются автоматически: архивируй старые при закрытой игре. В этот же момент можно удалить временный P90/control; следующий запуск создаст его заново. Не удаляй его во время работы.

## Доступ к консоли

Файловая консоль не открывает TCP-порт и не принимает команды чата. Граница доступа — права Windows на папку игры/P90/control. Пользователь с правом записи туда может отправлять локальные команды; встроенных паролей, ролей и криптографической аутентификации нет. Не делай control общей папкой для игроков. DLL плагина выполняет код с правами игры, поэтому устанавливай доверенные сборки.

## Поиск причины ошибки

| Симптом | Что проверить |
| --- | --- |
| Unsupported game build при установке | Та же сборка по шести SHA-256; одна версия Unity недостаточна |
| Existing mod/runtime detected | Выбрана чистая копия без старого загрузчика |
| Нет журнала BepInEx | Правильный EXE и расположение winhttp.dll, разрешён ли запуск файлов защитным ПО |
| Нет плагина в списке | DLL лежит в P90/plugins или непосредственно в одной папке внутри него; журнал загрузки, уникальный ID, API major |
| Faulted | Ошибка в Start, настройках или конфликт команды; журнал плагина |
| Command not available | Плагин активен, имя верное, команда действительно зарегистрирована |
| Only the active host/server can broadcast | Этот экземпляр создал сервер, а не подключился клиентом |
| No ready players / No shared PlayerAdmin identity | Дождаться загрузки персонажей и сетевых объектов |
| Supported=false | DisabledReason и adapter_build_check/adapter_failed в журнале запуска |
| PID/path/start mismatch | Игра ещё открыта, скрипт принадлежит этой копии, одинаковый уровень прав процессов |
| Нет ответа | Нет ли зависания главного потока; логи; не повторять вслепую операцию |
| session command limit reached | Лимит 10 000 запросов на процесс; перезапуск игры |
| SteamAPI_Init failed | Steam запущен, аккаунт доступен, игра запускается в штатном окружении |

Исправление UTC/местного времени для Windows PowerShell 5.1 уже включено. Не подменяй PID и время в session.json. Если нужна помощь, передай версию комплекта, команду, полный ответ, момент ошибки, журнал запуска и журнал нужного плагина, предварительно просмотрев личные данные.
