# Документация P90 Nexus 0.3.0

P90 Nexus — фреймворк C#-плагинов для играющего хоста SCP Project 90, Windows x64, конкретная сборка Unity 2022.3.16f1. Публичный контракт: **P90 API major 1**, целевая платформа **net6.0**. Обновление 0.3.0: 1 октября 2026. Плагины устанавливаются копированием собственной папки в P90/plugins и полным перезапуском игры.

Начинающему автору достаточно руководства по плагинам и справочника API. Для обычного запуска SDK и исходники не нужны. Все команды в документации выполняются из явно указанной папки; пути `D:\Games\...` — примеры, их нужно заменить своими.

## Что есть в первой версии

Обнаружение DLL, проверка метаданных, запуск и остановка плагинов, JSON-конфиги, JSONL-журналы, локальные команды оператора, события наблюдения сервера и готовых персонажей, снимок игроков и объявление через существующий RPC игры. Клиентский мод для этих функций архитектурно не предусмотрен.

Федор сообщил: «твоя сборка работает! И у других людей тоже». Это подтверждение практической работы переданного комплекта. Детальных журналов и результатов каждого сетевого сценария нет; полный набор сценариев нельзя считать автоматически пройденным. Автоматические и локальные проверки перечислены отдельно в руководстве выпуска.

API пока не содержит изменения ролей, урона, здоровья, инвентаря, выдачи предметов, бана, SteamID или управления раундами. Dedicated server, горячая замена DLL, независимые версии зависимостей и удалённая консоль не заявлены. Новые прикладные плагины могут потребовать расширения адаптера.

## Как устроен комплект

`GameFiles` — только устанавливаемые файлы запуска; `SDK` — самостоятельный инструментарий автора плагинов; `Development` — исходники и скрипты разработки нашего фреймворка; `Documentation` — это руководство. Установщик копирует только `GameFiles`. В комплект не входят исходные файлы игры, персональные логи, сессии управления и исследовательская чистая копия.

Название выпуска 0.2.0 относится к комплекту и метаданным загрузчика; версии отдельных сборок .NET могут отличаться. Совместимость плагинов проверяется по `PluginAttribute.ApiMajor`, а адаптера — по SHA-256 файлов игры. Совпадение номера Unity само по себе не обеспечивает совместимость.
